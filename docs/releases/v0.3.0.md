## What's new

- **Контекст** in settings: pick 16k / 32k / 64k and press **Применить**. The PC saves it to `config.json` and
  restarts the model, no reboot needed. A stopped model picks the new value up when it is turned on.
- Needs the updated control service on the PC (`windows/update-local-ai.ps1`). With the old one the app says the
  service is out of date.
- Control service: `GET /config` / `POST /config`; `config.json` is re-read before every model start (before, a
  changed `ctx` applied only after a reboot); llama-server now runs with `--parallel 1 -ub 256` (all context for one
  request, less GPU memory for prompt processing; `parallel` / `ubatch` in `config.json` override them).

## Install

Installed copies update through **Обновления**. New install: unzip and move `LocalAIBar.app` to `/Applications`;
on first launch right-click → Open (the app is not notarized). Requires macOS 14+.
