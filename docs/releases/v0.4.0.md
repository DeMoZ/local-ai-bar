## What's new

- **Модель** in settings: pick a model from the PC's models folder (👁 = understands images) and press
  **Применить**; the PC restarts the model with it. Where to put models and what goes with them:
  `docs/models.md`.
- **Crash notifications**: a macOS notification when the model crashes on the PC, with the exit code.
  **Перезапускать модель, если упала** in settings lets the PC start it again by itself (at most 3 times in
  10 minutes). Notifications can be turned off in settings.
- **PC load** under the model: memory, CPU, GPU load and GPU memory, memory of llama-server.
- **Live speed** next to the menu bar icon while the model answers (tokens per second, "…" while it reads the
  prompt).
- The control service also runs on a Mac (PowerShell 7) for models on the same machine.
- Release scripts can sign with a Developer ID and notarize (optional).

The new features need the updated control service on the PC. In PowerShell on the PC, as Administrator:
`irm https://raw.githubusercontent.com/DeMoZ/local-ai-bar/main/server/update-windows.ps1 | iex`.
With the old service the app works as before and says the service is out of date.

## Install

Installed copies update through **Обновления**. New install: unzip and move `LocalAIBar.app` to `/Applications`;
on first launch right-click → Open (the app is not notarized). Requires macOS 14+.
