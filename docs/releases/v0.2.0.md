## What's new

- **Updates**: the app checks for new versions by itself and installs them (Sparkle). The **Обновления** button checks right away.
- **♥ Поддержать**: ways to support the project, loaded from the public `DeMoZ/donations` repository.
- **Fix**: the panel no longer lets windows behind it show through.

## Install

Unzip and move `LocalAIBar.app` to `/Applications`. The app is ad-hoc signed (not notarized): on first launch
right-click → Open, or run `xattr -dr com.apple.quarantine /Applications/LocalAIBar.app`. Requires macOS 14+.
Later versions install through **Обновления**.
